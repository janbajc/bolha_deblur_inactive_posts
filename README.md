# Bolha Deblur

## Slovenščina

Lahka Chrome razširitev, ki odstrani zameglitev neaktivnih oglasov na [bolha.com](https://www.bolha.com).

### Funkcionalnosti
- Samodejno odstrani zameglitev neaktivnih oglasov
- Deluje tudi ob dinamičnih spremembah strani

### Namestitev
1. Kloniraj ali prenesi ta repozitorij.
2. Odpri **Chrome** (ali drug Chromium brskalnik, npr. Edge ali Brave).
3. Pojdi na `chrome://extensions/`.
4. Omogoči **Developer mode** (zgoraj desno).
5. Klikni **Load unpacked** in izberi mapo projekta.
6. Odpri [bolha.com](https://www.bolha.com) in razširitev bo odstranila zameglitev.

### Dovoljenja
Razširitev uporablja naslednje dovoljenje:

- **host_permissions** (`https://*.bolha.com/*`) - potrebno za zagon content skripte na straneh bolha.com.

Razširitev ne zbira, ne shranjuje in ne pošilja nobenih podatkov.

---

## English

A lightweight Chrome extension that removes blur from inactive posts on [bolha.com](https://www.bolha.com).

### Features
- Automatically removes blur from inactive posts
- Works with dynamic page updates

### Installation
1. Clone or download this repository.
2. Open **Chrome** (or any Chromium-based browser, such as Edge or Brave).
3. Go to `chrome://extensions/`.
4. Enable **Developer mode** (top right).
5. Click **Load unpacked** and select the project folder.
6. Open [bolha.com](https://www.bolha.com) and the extension will remove blur.

### Permissions
The extension requests the following permission:

- **host_permissions** (`https://*.bolha.com/*`) - required to run the content script on bolha.com pages.

The extension does not collect, store, or transmit any data.
